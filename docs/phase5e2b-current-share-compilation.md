# Phase 5E-2B current-share compilation boundary

The compiler owns selection. It replays the exact price-blind artifact, security compilation,
governed market-access result, Phase 5C dilution authority, current Fact/restatement authority, and
recursive share evidence before returning an eligible result.

Path precedence is direct, issued less treasury, then completed-event roll-forward, but precedence
applies only after every eligible path agrees numerically. Conflicting duplicate or cross-path
evidence blocks the result. Missing optional paths do not invalidate a stronger exact-date path.

Roll-forwards require all eight formal source-family searches and all twelve corporate-action
categories to close as observed, formal zero, or human-reviewed not applicable. Search silence is
never zero. Completed option, convertible, and warrant events must reconcile their remaining claim
and the frozen bridge treatment.

The implementation is internal-only. Its implementation and separate acceptance closeout passed
PR/main CI and exact-head read-only audit `2.3.2.3` as an engineering boundary. Independent
semantic review subsequently found that its source-based duplicate key can consume one legal event
multiple times. The historical closeout remains recorded, but Phase 5E-2B is subject to the
Phase 5E-2B.1 corrective sequence. Phase 5E-2C and later remain prohibited.

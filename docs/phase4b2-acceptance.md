# Phase 4B-2 acceptance contract

Phase 4B-2 is ready to merge only when:

- the compiler accepts only human-confirmed measurable Statements and their exact reviewed target
  evidence;
- every Commitment has a registered policy, compatible target roles, explicit scope and basis,
  and an unambiguous due date;
- narrative-only Statements produce no Commitment;
- KPI definition changes require an assumption-free deterministic bridge;
- withdrawal and supersession are lifecycle changes with no implied missed result;
- Phase 1 through 4B-1 regressions, Python 3.11/3.12/3.13, wheel, component lock, Plugin/Skill,
  and isolated read-only audit all pass with P0=P1=0; and
- no Outcome evaluator, Review builder, score, valuation, report, PDF, Publisher, or release tag is
  created.

Phase 4B-3 is the next stage.

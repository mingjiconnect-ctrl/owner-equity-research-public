# ADR 0007: Phase 4B-2 deterministic Commitment compiler

## Status

Accepted for Phase 4B-2 implementation.

## Decision

Compile `ManagementCommitment` only from the official-source review chain introduced in Phase
4B-1. The compiler must reproduce the confirmed metric components, scope, measurement basis, and
registered policy roles. It requires explicit baseline and condition evidence where the selected
policy or commitment strength demands them.

An exact date is preferred. Controlled relative fiscal dates are permitted only when issuer fiscal
metadata yields one unambiguous period. Narrative-only Statements return a manifest exclusion and
do not create blocked Commitments. Withdrawal and supersession are deterministic lifecycle
transitions, not performance conclusions.

## Boundary

Phase 4B-2 does not compare actual results, set Outcome status, build a ManagementReview, grade
management, score, value, report, or publish.

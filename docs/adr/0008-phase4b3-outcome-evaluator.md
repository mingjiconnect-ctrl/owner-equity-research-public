# ADR 0008: Phase 4B-3 deterministic Outcome evaluator

## Status

Accepted for Phase 4B-3 implementation.

## Decision

Outcome status is generated by code from the registered Commitment policy. The evaluator requires
official result evidence, exact component/scope/basis/period comparability, and explanatory Claims
that cover the formal result inputs. Claims never override arithmetic.

Reported growth and cumulative values are generated as assumption-free calculations. Constant
currency, organic, inorganic, and KPI bridges require named deterministic calculations. Before the
deadline an active Commitment is pending; after the deadline absent disclosure is unverifiable and
unresolved comparability is blocked. Withdrawal and supersession remain lifecycle states.

The `maintain_or_improve` policy uses baseline components and no target binding; the v2 Commitment
Schema now expresses that invariant while requiring targets for every other policy.

## Boundary

Phase 4B-3 does not build ManagementReview coverage, run company shadows, grade management, score,
value, report, or publish.

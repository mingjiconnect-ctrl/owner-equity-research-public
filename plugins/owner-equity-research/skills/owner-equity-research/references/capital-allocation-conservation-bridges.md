# Capital-allocation conservation bridges

Use this reference only after a capital-allocation Event has been compiled from reviewed official
evidence.

1. Select one registered bridge policy and supply its exact role set from Facts already bound to
   the Event.
2. Require one issuer, one comparable period, one currency where applicable, official sources,
   and evidence no later than the data cutoff.
3. Normalize monetary scales before arithmetic. Preserve shares and use `currency_per_share` only
   for registered per-share multiplication or division.
4. Missing consideration, refinancing, SBC, other issuance, liquidity, or other required roles
   block the bridge. Do not replace nondisclosure with zero.
5. Emit only an assumption-free `CalculationResult` with calculator version, code hash, typed
   input bindings, and stable input/output fingerprints.

Do not interpret a zero residual as proof of value creation. Do not evaluate an Outcome, build a
CapitalAllocationReview, run a Shadow, score capital allocation, use market prices, value the
issuer, recommend an investment, render a report/PDF, or invoke a Publisher.
